# EV Charging Station Finder

A web app that helps electric vehicle drivers plan a charging stop. Enter a city and the app shows nearby EV charging stations, where to get food while your car charges, and how long it takes to get there.

> **Status:** Working, and still being improved.

## Why I built this

Finding a charger is only part of the problem. Drivers also need to know how far it is, how long the trip will take, and what they can do while the car charges. This project puts all of that in one place.

## Features

- **Register and sign in** to use the app
- **Search by city** to find EV charging stations
- **See station locations** so you know where to go
- **Find food nearby** so you can eat while your vehicle charges
- **Travel time estimate** to each station

## How to use

1. Create an account on the registration page.
2. Sign in.
3. Type the name of a city in the search box.
4. Pick a charging station from the results to see its location, nearby food options and travel time.
